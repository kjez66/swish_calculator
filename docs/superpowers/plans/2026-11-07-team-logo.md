# Team Logo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An optional team logo, uploaded in the till's Inställningar, that shows
on the customer display, in the till's own payment view and on the PDF sales
report.

**Architecture:** The kassa's Durable Object stores one re-encoded PNG under a
new `logo` key. Operator-only `PUT` and `DELETE` routes change it. A
token-free `GET /api/logo?roomId=…&v=…` serves it, cacheable for a year
because the version is in the URL. The till learns that URL from
`/api/state`, and the displays from the `room` event. Pages show it with plain
same-origin `<img>`s, so the CSP stays as it is. The PDF gets a JPEG of it,
drawn by the till, and embeds it with `/DCTDecode`.

**Tech Stack:** Cloudflare Workers + Durable Objects (SQLite storage), plain JS
modules on the till, ES5 on the display, vitest with
`@cloudflare/vitest-plugin`, Biome.

**Spec:** `docs/superpowers/specs/2026-11-07-team-logo-design.md`

## Global Constraints

- The logo is optional. Without one, every surface looks exactly as it does
  today, and the PDF is byte-for-byte unchanged.
- Server limit: **256 KB** (262 144 bytes). PNG only, checked by its 8-byte
  signature `89 50 4E 47 0D 0A 1A 0A`. Errors: `invalid_logo` (400) and
  `logo_too_large` (413).
- The upload is re-encoded on the phone: at most **512 × 512 px**, aspect kept,
  transparency kept, exported as PNG. The picker accepts
  `image/png,image/jpeg,image/webp`. No SVG.
- Logo URL: `/api/logo?roomId=<roomId>&v=<version>`. `version` is the first 16
  hex characters of the PNG's SHA-256.
- `GET /api/logo` headers: `Content-Type: image/png`,
  `Cache-Control: public, max-age=31536000, immutable`, plus the API's security
  headers.
- No CSP change: no `data:` or `blob:` images. A logo preview drawn from a
  local file goes on a `<canvas>`, never on an `<img>` with a `blob:` URL.
- `public/display.js` stays ES5 with no trailing commas
  (`tests/display_es5.test.js`). Every `clamp()`/`min()` in `display.css`
  has a fixed-px fallback on the line before (R28).
- No inline `style=`, `<style>`, inline script or `on…=` attributes in the
  pages (`tests/headers.test.js`).
- Copy, exactly: section heading **Logga (valfri)**; buttons **Välj bild** /
  **Byt bild** and **Ta bort**; errors **"Bilden kunde inte läsas. Välj en
  PNG- eller JPEG-bild."** and **"Bilden är för stor."**
- Nothing is saved before **Spara**, and **Avbryt** discards a picked or
  removed logo. Save order: settings, products, then the logo.
- A broken image never shows. An image that fails to load stays hidden, and a
  logo that cannot be loaded never blocks the PDF.

## Review Focus

1. **Extreme shapes:** a 2000×200 banner or a 200×2000 portrait logo. It is
   fitted to its box on every surface. The QR keeps its size, and Klar stays
   on screen on a 320×568 till. (Task 3 step 6, Task 4 step 7; PDF in Task 2's
   tall-logo test.)
2. **A transparent PNG in the PDF:** JPEG has no alpha, so unless the canvas is
   filled white first, the background turns black. (Task 4 step 7.)
3. **An unreadable pick:** a renamed text file, a corrupt image, or a HEIC that
   the browser cannot decode. The error appears at the field, nothing is
   uploaded, and the old logo stays. (Task 4 step 7.)
4. **A stale logo URL:** the logo is replaced on another phone while this
   display or till still has the old URL. The old URL answers 404, and the
   image hides instead of showing broken. The next `room` event or refresh
   brings the new one, and the PDF is made without the logo. (Task 1 test
   "a replaced or removed logo…"; Task 3 step 6; Task 4 step 7.)
5. **Spara fails at the logo step**, after settings and products have saved
   (network drop). The dialog stays open with the error, and pressing Spara
   again finishes the job. (Task 4 step 7.)

const JPEG = Uint8Array.from([0xff, 0xd8, 0xff, 0xe0, 0x0a, 0x28, 0x29, 0x5c, 0x80, 0xff, 0xd9]);

test("with a logo, the first page draws it as an embedded JPEG, top right", () => {
  const pdf = raw({ jpeg: JPEG, width: 200, height: 100 });

  const [id, image] = [...objects].find(([, o]) => o.includes("/Subtype /Image"));

- [ ] **Step 5: Behaviour in `public/app.js`**

- **State.** `let logoUrl = null`, set in `refresh()` from `state.logoUrl`, and
  `let logoDraft = null`. While the dialog is open, `logoDraft` is either
  `{ remove: true }` or `{ png: Blob }`. `null` means unchanged.
- **Payment view.** `renderAll()` handles `#qrTeamLogo` with the same
  hide-until-`onload` and hide-on-`onerror` rule as the display. It sets `src`
  only when `logoUrl` changed.
- **Shrinking.** Add `async function shrinkLogo(file): Promise<{ png: Blob, canvas: HTMLCanvasElement }>`:
  - `createImageBitmap(file)`;
  - scale by `Math.min(1, 512 / Math.max(w, h))`;
  - draw onto a canvas of the rounded size, without filling it, so
    transparency is kept;
  - `canvas.toBlob(resolve, "image/png")`.
  - It throws on any failure.
- **Preview.** Add `drawPreview(source)`. It sizes `#logoPreview` to the source
  and draws it. The source is the shrunk canvas, or an `Image` loaded from
  `logoUrl`.
- **openSettings.** It resets `logoDraft = null`. When there is a `logoUrl`, it
  loads it into an `Image` and calls `drawPreview` on load. It sets the pick
  button's text (Välj bild / Byt bild), `#logoRemove.hidden`, and
  `#logoPreview.hidden`.
- **`#logoPick`** clicks `#logoFile`.
- **`#logoFile` change.** It runs `shrinkLogo(file)`:
  - On failure, `fieldError($("logoFile"), "Bilden kunde inte läsas. Välj en PNG- eller JPEG-bild.", $("logoPick").parentElement)`
    and focus `#logoPick`. Anything already saved stays as it was.
  - On success, `logoDraft = { png }`, draw the preview, show Ta bort, and set
    the button text to Byt bild.
  - Reset `#logoFile.value` so the same file can be picked again.
- **`#logoRemove`** sets `logoDraft = { remove: true }`, hides the preview and
  itself, and sets the button text to Välj bild.
- **Spara.** After `PUT /api/products`:
  - `{ png }` becomes `await api("PUT", "/api/logo", png)`;
  - `{ remove }` becomes `await api("DELETE", "/api/logo")`.
  - Error mapping gains `logo_too_large`, shown as "Bilden är för stor." at the
    logo field, and `invalid_logo`, shown as the unreadable-image message.
    Anything else uses the existing generic message. The dialog stays open
    either way.
- **PDF.** Add `async function logoJpeg(): Promise<{ jpeg, width, height } | null>`:
  - Return `null` when there is no `logoUrl`.
  - Load an `Image` from `logoUrl`.
  - Draw it onto a canvas of its natural size that has been filled `#fff`
    first (Review Focus 2).
  - `toDataURL("image/jpeg", 0.92)`, then decode the base64 after the comma
    with `atob` into a `Uint8Array`.
  - Return `null` on any error.
  - The Ladda ner PDF handler awaits it and passes `logo: (await logoJpeg()) ?? undefined`.

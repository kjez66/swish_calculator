# Drop Deno Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove Deno from the project, so a clone needs only Node.js and npm. The 39
Deno tests move into the existing Vitest setup inside workerd, and Biome replaces
`deno lint` and `deno fmt`.

**Architecture:** The 9 `tests/*_test.js` files become `tests/*.test.js` and run in the
Vitest config that already runs `tests/worker/` in workerd
(`@cloudflare/vitest-plugin`). Tests that read `public/` files fetch them through a new
`ASSETS` binding on Workers Static Assets, so they check what phones are served.
Biome 2.5.15, configured in `biome.jsonc`, lints and formats. A `.gitattributes` keeps
every checkout LF, so the format check passes on Windows too.

**Tech Stack:** Vitest 4 with `@cloudflare/vitest-plugin` 1.4 (workerd), Wrangler 4,
Biome 2.5.15, npm 11, Node.js 22+.

**Spec:** `docs/superpowers/specs/2026-10-12-drop-deno-design.md`

## Global Constraints

- The app does not change: no behaviour change in `public/` or `src/`. The only source
  edits are comments, and formatting in Task 4.
- Ported tests keep their exact names and check the same things.
- `public/display.js` must stay ECMAScript 5: no trailing commas in calls, no arrow
  functions, no template literals.
- Exact versions: `@biomejs/biome` 2.5.15, `jsqr` 1.4.0, `acorn` 8.14.0
  (`npm install -D -E`).
- Biome settings: 2-space indent, 90-character lines, double quotes, LF line endings.
  Excluded: `docs/`, `public/brand/`, `.claude/`, SVG files, `package-lock.json`, and
  everything in `.gitignore` (`node_modules/`, `.wrangler/`).
- The one-time reformat is its own commit, with no other changes.
- `docs/` keeps its Deno mentions, except the spec amendment in Task 3.
- Run commands from the repo root. In PowerShell, use `npm.cmd` and `npx.cmd`.
- Every commit message ends with:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

1. **A formatter makes `display.js` ES2015+.** Biome's default adds trailing commas to
   multi-line calls, which old phones cannot parse. Expected: `display.js` keeps
   parsing as ES5 after formatting. Covered by the ES5 test (Task 2), run again after
   the reformat in Task 4.
2. **A Windows checkout with CRLF line endings fails `npm run check`.** Expected: a
   clean checkout passes. Covered by `.gitattributes` (Task 3) and a CRLF check in
   Task 4, Step 3.
3. **A ported test silently stops running or checking.** Examples: the Vitest glob
   misses a file, or `assertThrows` becomes a `toThrow` that no longer checks the
   message. Expected: exact test counts after each task (82 after Task 1, 88 after
   Task 2), and a deliberate-failure check in Task 1, Step 6.
4. **A missing `public/` file passes as an empty string.** Expected: fetching a file
   that does not exist fails the test with its path. Covered by
   `tests/assets.test.js` (Task 2).
5. **The `ASSETS` binding breaks the deploy.** Expected: `wrangler deploy --dry-run`
   accepts the config. Covered in Task 2, Step 9.

Create `tests/qr.test.js`:

```js
import jsQR from "jsqr";
import { expect, test } from "vitest";
import { QUIET_ZONE_MODULES, toMatrix, toSvg } from "../src/qr.js";

const PAYLOAD = "C0701234567;249.00;Kaffebaren #47;0";

/**
 * Rasterize a module matrix straight to RGBA pixels. No SVG rasterization is
 * needed to prove the encoder is correct, and this keeps the test dependency-light.
 */
function rasterize(matrix, scale = 8, quiet = QUIET_ZONE_MODULES) {
  const n = matrix.length;
  const side = (n + quiet * 2) * scale;
  const px = new Uint8ClampedArray(side * side * 4).fill(255);
  for (let r = 0; r < n; r++) {
    for (let c = 0; c < n; c++) {
      if (!matrix[r][c]) continue;
      for (let dy = 0; dy < scale; dy++) {
        for (let dx = 0; dx < scale; dx++) {
          const y = (r + quiet) * scale + dy;
          const x = (c + quiet) * scale + dx;
          const i = (y * side + x) * 4;
          px[i] = px[i + 1] = px[i + 2] = 0;
        }
      }
    }
  }
  return { px, side };
}

test("a generated QR decodes back to the exact payload", () => {
  const { px, side } = rasterize(toMatrix(PAYLOAD));
  const decoded = jsQR(px, side, side);
  expect(decoded?.data).toBe(PAYLOAD);
});

test("Swedish characters survive the round-trip", () => {
  // Without the UTF-8 stringToBytes override the encoder emits Latin-1 and these
  // come back as mojibake.
  const payload = "C0701234567;99.00;Åsas Bröd åäö #3;0";
  const { px, side } = rasterize(toMatrix(payload));
  expect(jsQR(px, side, side)?.data).toBe(payload);
});

test("a long note at the message limit still decodes", () => {
  const payload = `C0701234567;19999.00;${"ä".repeat(50)};0`;
  const { px, side } = rasterize(toMatrix(payload));
  expect(jsQR(px, side, side)?.data).toBe(payload);
});

test("toMatrix returns a square boolean matrix", () => {
  const m = toMatrix(PAYLOAD);
  expect(Array.isArray(m)).toBe(true);
  for (const row of m) expect(row.length).toBe(m.length);
  expect(typeof m[0][0]).toBe("boolean");
});

test("toSvg includes a four-module quiet zone in its viewBox", () => {
  const n = toMatrix(PAYLOAD).length;
  const svg = toSvg(PAYLOAD);
  expect(QUIET_ZONE_MODULES).toBe(4);
  expect(svg).toContain(`viewBox="0 0 ${n + 8} ${n + 8}"`);
});

test("toSvg paints an opaque white background", () => {
  // A transparent QR inheriting a dark page background is unscannable.
  const svg = toSvg(PAYLOAD);
  expect(svg).toContain('<rect width="100%" height="100%" fill="#ffffff"');
  expect(svg.includes('fill="none"')).toBe(false);
  expect(svg.includes("transparent")).toBe(false);
});

test("toSvg draws crisp edges and scales without a fixed pixel size", () => {
  const svg = toSvg(PAYLOAD);
  expect(svg).toContain('shape-rendering="crispEdges"');
  expect(/\swidth="\d+px"/.test(svg)).toBe(false);
});

test("the SVG path covers exactly the dark modules of the matrix", () => {
  const matrix = toMatrix(PAYLOAD);
  const expectedDark = matrix.flat().filter(Boolean).length;
  const svg = toSvg(PAYLOAD);
  // One "M<x> <y>h1v1H<x>z" sub-path is emitted per dark module.
  const drawn = (svg.match(/M\d+ \d+h1v1H\d+z/g) ?? []).length;
  expect(drawn).toBe(expectedDark);
});

test("toSvg names the code for screen readers, escaping the label", () => {
  expect(toSvg(PAYLOAD)).toContain('role="img" aria-label="Swish QR-kod"');
  expect(toSvg(PAYLOAD, 'Kod för "A" & <B>')).toContain(
    'aria-label="Kod för &quot;A&quot; &amp; &lt;B&gt;"',
  );
});
```

```js
import { expect, test } from "vitest";
import {
  buildPayload,
  MESSAGE_MAX_CHARS,
  normalizePayee,
  sanitizeMessage,
} from "../public/shared/swish.js";

test("normalizePayee accepts the shapes people actually type", () => {
  expect(normalizePayee("0701234567")).toBe("0701234567");
  expect(normalizePayee("070-123 45 67")).toBe("0701234567");
  expect(normalizePayee("+46 70 123 45 67")).toBe("0701234567");
  expect(normalizePayee("46701234567")).toBe("0701234567");
  expect(normalizePayee("0046701234567")).toBe("0701234567");
});

test("normalizePayee accepts merchant numbers unchanged", () => {
  expect(normalizePayee("1231181189")).toBe("1231181189");
  expect(normalizePayee("123 118 11 89")).toBe("1231181189");
});

test("normalizePayee rejects anything that is not a Swish number", () => {
  // 08 is a landline; 12 digits is not a Swish number; letters never are.
  for (
    const bad of ["", "12345", "0801234567", "070123456789", "07012345ab", "9991234567"]
  ) {
    expect(() => normalizePayee(bad), bad).toThrow("invalid_payee");
  }
});

test("sanitizeMessage removes the field separator", () => {
  // An unescaped ';' would shift every following field and corrupt the amount.
  expect(sanitizeMessage("Kalle; Bagare")).toBe("Kalle Bagare");
  expect(sanitizeMessage(";;;")).toBe("");
});

test("sanitizeMessage strips control characters and collapses whitespace", () => {
  expect(sanitizeMessage("Kaffe\nBaren\t #7")).toBe("Kaffe Baren #7");
  expect(sanitizeMessage("  spaced   out  ")).toBe("spaced out");
  // U+0007 (bell) is a non-whitespace control character: deleted, not turned into a space.
  expect(sanitizeMessage("bell\x07here")).toBe("bellhere");
});

test("sanitizeMessage deletes C1 controls and bidi overrides/isolates", () => {
  // C1 controls U+0080-U+009F (incl. U+0085 NEL, which \s does not match): deleted.
  expect(sanitizeMessage("a\u0080b\u0085c\u009Fd")).toBe("abcd");
  // Bidi marks, embeddings/overrides and isolates would let a store name
  // visually reorder the note (e.g. move the order number): deleted.
  expect(
    sanitizeMessage(
      "‎K‏a‪f‫f‬e‭ ‮#⁦7⁧⁨⁩",
    ),
  ).toBe("Kaffe #7");
});

test("sanitizeMessage truncates by code point, not UTF-16 unit or byte", () => {
  expect(MESSAGE_MAX_CHARS).toBe(50);

  // 'å' is one code point but two UTF-8 bytes: byte-counting would truncate early.
  const swedish = "å".repeat(60);
  expect(Array.from(sanitizeMessage(swedish)).length).toBe(50);

  // An emoji is one code point but two UTF-16 units: unit-counting would split it
  // in half and emit a lone surrogate.
  const emoji = "🎪".repeat(60);
  const out = sanitizeMessage(emoji);
  expect(Array.from(out).length).toBe(50);
  expect(out.includes("�")).toBe(false);
  // A broken (UTF-16-unit) truncation would cut a surrogate pair in half and
  // leave an orphaned HIGH surrogate as the very last unit. A correct,
  // code-point-based truncation that ends on a full character never does this
  // -- when it ends on a supplementary-plane character, the last unit is that
  // character's LOW surrogate (\uDC00-\uDFFF), which this must not flag.
  expect(/[\uD800-\uDBFF]/.test(out.slice(-1))).toBe(false);
});

test("buildPayload emits the exact expected string", () => {
  expect(
    buildPayload({ payee: "0701234567", totalOre: 24900, message: "Kaffebaren #47" }),
  ).toBe("C0701234567;249.00;Kaffebaren #47;0");
});

test("buildPayload locks all three fields with flag 0", () => {
  const payload = buildPayload({ payee: "0701234567", totalOre: 100, message: "x" });
  expect(payload.endsWith(";0")).toBe(true);
  expect(payload.split(";").length).toBe(4);
});

test("buildPayload normalizes and sanitizes its inputs", () => {
  expect(
    buildPayload({ payee: "+46 70 123 45 67", totalOre: 1990, message: "A; B" }),
  ).toBe("C0701234567;19.90;A B;0");
});
```

```js
import { env } from "cloudflare:workers";

/**
 * A file from public/, fetched the way a phone gets it. `path` is the URL path,
 * e.g. "/display.js". The pages redirect to their short URLs (/index.html to /),
 * and fetch follows that. A missing file fails the test instead of reading as "".
 * @param {string} path
 */
export async function asset(path) {
  const res = await env.ASSETS.fetch(`https://kassa.test${path}`);
  if (!res.ok) throw new Error(`${path}: HTTP ${res.status}`);
  return res;
}

/** @param {string} path */
export const assetText = async (path) => (await asset(path)).text();

/** @param {string} path */
export const assetBytes = async (path) =>
  new Uint8Array(await (await asset(path)).arrayBuffer());
```
